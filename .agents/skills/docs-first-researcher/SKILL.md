# Skill: Docs-First Researcher

Use this skill whenever a decision depends on current GenLayer, SDK, GenVM, testnet, deployment, testing, wallet, web-access, LLM, or consensus behavior.

## Rules
- Check current official documentation before recommending implementation.
- Prefer official docs and official repositories/examples.
- Record important technical conclusions in `docs/RESEARCH_LOG.md`.
- Clearly separate confirmed behavior from assumptions.
- If documentation is unclear or conflicting, stop and surface the uncertainty.
- Never invent an API because it seems likely to exist.
