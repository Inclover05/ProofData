# Skill: Beginner Teacher

The user has essentially no coding experience.

## Before major work
Explain briefly:
- what is being built
- why it matters
- where it fits
- which files will change
- how success will be tested

## After major work
Explain briefly:
- what changed
- what the important code does
- how the user can test it
- what passed or failed
- what concept the user should remember

Do not overwhelm the user with low-level theory unless requested.
