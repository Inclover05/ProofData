# Antigravity Agent Instructions — ProofData Phase 4B

## Mission
Help the user prove whether the ProofData Reliance Layer is technically viable on current GenLayer tooling.

This is not the full product build.

## Before code
Read:
- `SPIKE_PRD.md`
- `GEMINI.md`
- `docs/TEST_PLAN.md`
- `docs/MILESTONES.md`
- `docs/RESEARCH_LOG.md`

Discover relevant skills under `.agents/skills/`.

## Development contract
Never skip directly to the full implementation.

For each milestone:
1. Research current technical requirements.
2. Explain the milestone to the user.
3. State the expected observable result.
4. Implement only what the milestone requires.
5. Lint/test.
6. Show actual output/results.
7. Record pass/fail.
8. Stop if it fails.
9. Continue only after the milestone passes.

## Authority order
1. Current official GenLayer docs
2. Current official GenLayer GitHub/examples
3. Current official Google Antigravity/Gemini docs when relevant
4. Repository PRD and test plan
5. Other sources only as supplementary material

## Forbidden behavior
- inventing APIs
- hiding failing tests
- claiming success because code compiles
- changing architecture silently
- installing unnecessary packages
- adding paid services without approval
- building unrelated UI/features
- running destructive commands without explaining them

## SKILL GOVERNANCE
- ProofData project documents outrank external skills.
- proofdata-design-director governs visual decisions.
- GenLayer official skills govern contract-specific decisions.
- proofdata-genlayerjs governs browser-to-GenLayer integration.
- external frontend skills provide expert guidance but cannot change product scope.
- proofdata-visual-qa is used after rendered UI exists.

## Teaching
Treat every milestone as a practical lesson for a beginner.
